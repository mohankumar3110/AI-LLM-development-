⚠️ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: "CUDA out of memory"
Solution:
  • Reduce batch_size in config.py (already set to 1)
  • Use CPU instead: modify config.py
  • Close other GPU applications

Problem: "PyTorch not installed"
Solution:
  • Run: python -m pip install torch --index-url https://download.pytorch.org/whl/cu118
  • Or try automatic installation: python QUICK_START.py (option 3)

Problem: "Model takes too long"
Solution:
  • Use GPU: Install CUDA drivers (nvidia.com)
  • Or reduce dataset size: edit config.py
  • Increase gradient_accumulation_steps for faster training

Problem: "Data files not found"
Solution:
  • Check data/ folder contains: train.jsonl, val.jsonl, test.jsonl
  • Run: python QUICK_START.py (option 5) to verify
